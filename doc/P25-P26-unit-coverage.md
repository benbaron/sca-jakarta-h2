# P25 and P26 unit coverage ledger

This ledger maps every implemented P25/P26 slice to behavioral automated coverage. Fixture-only classes are omitted. The Maven suite remains authoritative; this list prevents a completed slice from relying only on source-shape checks or manual acceptance.

P27's [integrated portability audit](P27-S4-portability-audit.md) supplements these feature tests. `ClosePortabilityAuditTest` verifies complete persisted-row/trigger recovery for original/reversed P25 transfers and reviewed P27 closes, native retry and restored period protection. S4B adds budget plan/line metadata and S4C adds operational transfer metadata below. This recovery test does not assert all-feature SCLX fidelity.

`SclxBudgetMetadataTest` adds P27-S4B behavioral coverage for P26 budget fiscal dates and exact archived/draft/active plan and line history, cross-company/inactive dimensions, deterministic export, legacy absence, malformed data, conflict/Keep target, restart/retry, denied import and late rollback. Category-master descriptive metadata remains a separate S4 completion concern.

P27-S4C adds `SclxFundTransfersTest` and expands `FundTransferSclxTest`/`FundTransferMigrationTest`: original/reversal/reversal-of-reversal, unlinked legacy facts, exact source metadata/UUID/request provenance, native future reversal/correction protection, deterministic bytes, remapped company/IDs, changed/stripped/conflicting input, unsupported/malformed graphs, request collisions, legacy absence, restart/retry, Viewer denial and late rollback. S4D remains the full integrated/category/evidence gate.

P27-S4D2 adds `SclxBudgetCategoriesTest` and `BudgetCategoryPortableIdentityMigrationTest`: full referenced/unused/inactive master facts, exact text/times, stable Budget/Journal relationships, remapping, code/UUID conflicts and Keep target, native edits/rename, stale rows, legacy absence, denial/late rollback/retry, V91 upgrade/UUID restart and unchanged alias links/write guards. This supplements P26 planning tests and does not replace S4D3 integrated acceptance.


P27-S4D3 adds `IntegratedPortabilityTest`: one populated P24–P27 company through real-file cross-company/native-ID remapping, exact supported graph/history and dated canonical reports, restart/no-op retry, populated-target Keep target, unsupported versions, audited Viewer denial, late rollback, and full-table/trigger backup recovery including credentials/preferences/aliases/another company. `BalanceSheetContraAccountTest` covers contra asset/liability/equity section signs and unchanged Trial Balance sides. See the [integrated contract](P27-S4D3-integrated-portability.md) for scope and the separately tracked reconciliation-policy follow-up.
