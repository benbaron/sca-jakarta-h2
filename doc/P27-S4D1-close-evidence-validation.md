After PR #395 merged at `6ed44f63`, split S4D into this evidence-validation slice, S4D2 category-master portability, and S4D3 integrated compatibility/recovery. Each requires the preceding merge. Parent S4 and P28 remain gated.

Recognize exactly action `CLOSE_REVIEW_RECORDED` plus entity `CloseReview`. A shared pure codec validates its required after-value before Preview/Save mutation, export publication, caller-owned audit restoration and typed history reading. Require version 1, exact required fields/types, bounded UTF-8 payload, ISO ordered dates/capture instant, SHA-256-shaped command/revision/backup fingerprints, typed unique finding identities/severities/destinations, one to 100 unique bounded external references, true boolean attestation and bounded note/reasons. Reasons may name only retained WARNING findings. Missing/null fields, duplicate JSON keys, trailing content, coercible wrong types and unsupported versions/fields reject visibly. Blockers may remain in factual reviews; all warnings need reasons only for a new interactive close.

Preserve source JSON text, whitespace, source-native references, finding details/IDs, dates, revision/hash, actor/time and request identity as historical facts. Do not rewrite local identifiers, recompute historical findings from target data, fetch references or claim verified documents. Unknown action/entity pairs retain generic opaque audit semantics. Existing identity/conflict/Keep target, authorization, file/target revalidation and atomic rollback remain authoritative. Imported findings never authorize a new close; canonical current checks remain unchanged. No schema, UI/Save action, approval workflow or second ledger.
